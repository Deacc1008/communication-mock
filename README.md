# KDK Communication & Renewal Manager — Interactive Prototype

Static GitHub Pages prototype for communication and renewal management inside the KDK Licensing Application.

## Files
- `index.html` — entry page
- `assets/css/style.css` — UI styling
- `assets/js/data.js` — dummy Subscription Master, templates, campaigns and history
- `assets/js/app.js` — navigation and interactive behaviour
- `.nojekyll` — serves the static files directly on GitHub Pages

## Demo behaviour
- Dashboard → Create Campaign
- Templates → WhatsApp / Email Templates
- Templates → New Template
- Campaign Manager → Create Campaign
- Schedule → Run Scheduler
- History → Export to CSV

Dummy data only. Do not add real customer PII to this public prototype.
